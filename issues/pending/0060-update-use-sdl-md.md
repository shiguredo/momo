## 目的

`doc/USE_SDL.md` は `--use-sdl` により受信映像を表示する機能を案内するドキュメントだが、記載が現行の Momo の実装と一致していない。以前は参考スクリーンショットに、既に削除されたセルフビュー機能 (旧 `--show-me`) の映像が写っており、存在しない機能があたかも利用できるように見えていた。

スクリーンショットの差し替えは PR #373 (コミット 7d8165f6) で対応済みだが、ドキュメント全体としては現行実装に合わせた見直しが行われておらず、古い記載が残っている。ドキュメント全体を現行の Momo に合わせてリライトする。

## 現状

- 旧 `--show-me` は 2023 年に削除済み (コミット 12f0ecbb)。参考スクリーンショットにセルフビューが写っていた問題は PR #373 (コミット 7d8165f6) で画像が差し替え済みで、現在の画像にセルフビューは写っていない
- 「Sora モード」の `--role` の説明が「sendrecv はマルチストリームの場合のみ利用できます」となっているが、 `--multistream` は 2022 年に削除されてマルチストリームは常に有効になっており (コミット 18be83eb)、この条件は現行の実装に対応しない
- 「Sora モード」で `--spotlight` は案内しているが、 `src/util.cpp` にある対の `--spotlight-number` が案内されていない

## 設計方針

- `doc/USE_SDL.md` の全記載を `src/util.cpp` のオプション定義と `src/sdl_renderer/sdl_renderer.cpp` のキー操作に突き合わせ、現行の Momo と一致させる
- SDL のオプション (`--use-sdl` / `--window-width` / `--window-height` / `--fullscreen`) と Sora モードで併用するオプション (`--role` / `--spotlight` / `--spotlight-number`) の説明を整理する
- 削除済み機能 (`--show-me` など) や存在しない条件の記載が残らないようにする
- スクリーンショットは現行の `--use-sdl` の表示と一致したものを利用する
- 文中のコマンド例は実際に動作確認したものにする

## 完了条件

- `doc/USE_SDL.md` の全記載が現行の Momo の実装と一致している
- 削除済みの機能・オプションや、存在しない条件が記載されていない
- スクリーンショットが現行の `--use-sdl` の表示 (受信映像のみが表示され、セルフビューは表示されない) と一致している
- コマンド例が現行のオプション名と一致し、動作確認されている
